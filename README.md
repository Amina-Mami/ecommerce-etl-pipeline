# ecommerce-etl-pipeline
Une entreprise retail reçoit des données de ventes depuis plusieurs sources (API fournisseur, exports CRM en CSV, base de données commandes).
L'objectif est de centraliser ces données dans un entrepôt de données pour permettre des analyses BI.
